# Credit Card Fraud Detection

Machine-learning portfolio project for identifying suspicious transactions.

### Approach
- Generate a reproducible synthetic transaction dataset
- Handle class imbalance with stratified splitting
- Train Logistic Regression and Random Forest models
- Compare precision, recall, F1 and confusion matrix

Metrics are generated by the included script; this repository does not claim a predetermined accuracy.

### Run
```bash
pip install -r requirements.txt
python fraud_detection.py
```
