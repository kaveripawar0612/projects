# Sales Performance Dashboard

A recruiter-ready sales analytics dashboard built with Python, Pandas, Plotly and Streamlit.

## Features
- Revenue, profit, orders and average-order-value KPIs
- Monthly sales and profit trend
- Regional performance comparison
- Category and product analysis
- Interactive filters for region, category and date
- Responsive dashboard layout

## Dataset
This project uses a **synthetic sample dataset** generated for portfolio demonstration. It is not presented as real business data.

## Tech Stack
Python • Pandas • Plotly • Streamlit

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
