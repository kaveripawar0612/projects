# AI Image Forgery Detection

Computer-vision portfolio project for analyzing potentially manipulated images.

### Pipeline
Upload image → preprocessing → image statistics / artifact analysis → heatmap-style visualization → forensic report.

This repository contains a transparent baseline rather than a fabricated deepfake detector. A production model should be trained and validated on representative manipulation datasets.

### Stack
Python • OpenCV • NumPy • Streamlit

### Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
